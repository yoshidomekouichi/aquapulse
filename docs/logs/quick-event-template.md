# 簡易イベント記録テンプレート

Phase 1a期間中、スマホメモや手元のメモから素早く記録するためのテンプレートです。

## クイック記録用（コピペして使用）

```
---
日時: 2026-MM-DD HH:MM
種類: [センサー移動 | エアコンON | エアコンOFF | エアコン温度 | エアコン風量 | ファンON | ファンOFF | その他]
内容: 
気温: °C / 湿度: %
メモ: 
```

## 記録例

### エアコン操作

```
---
日時: 2026-08-02 15:30
種類: エアコンON
内容: 温度26°C、風量自動に設定
気温: 32.5°C / 湿度: 65%
メモ: Tapoアラートで28°C超えを確認したため
```

### ファン操作

```
---
日時: 2026-08-02 08:00
種類: ファンON
内容: Tapoスマートプラグでファン電源ON
気温: 27.8°C / 湿度: 68%
メモ: 朝のスケジュール稼働
```

### 温度変更

```
---
日時: 2026-08-02 18:00
種類: エアコン温度
内容: 26°C → 25°Cに変更
気温: 29.1°C / 湿度: 64%
メモ: 気温がまだ高いため1°C下げる
```

## Tips

- **スマホメモアプリで記録**: 外出先でも記録可能
- **Tapoアプリから気温確認**: リアルタイムの温度・湿度をすぐ確認
- **最低限の情報**: 日時、種類、内容だけでもOK（後で詳細追加可能）
- **1日の終わりに転記**: `docs/logs/intervention-events.md`に整形して記録

## Google Forms対応（将来）

より楽に記録したい場合は、`docs/how-to/record-manual-events-forms.md`を参照してGoogle Formsを設定してください。スマホから数タップで記録可能になります。
