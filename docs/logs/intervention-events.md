# Intervention Events Log

このファイルは、Phase 1a（監視のみ）期間中の手動介入イベントを記録します。
ESP32自動記録システム稼働後は、BigQueryの`control_events`テーブルに移行します。

## イベント記録フォーマット

各イベントは以下の形式で記録してください：

```
### YYYY-MM-DD HH:MM (JST)
- **アクション**: [sensor_relocation | ac_on | ac_off | ac_temp_change | ac_fan_change | fan_on | fan_off | other]
- **詳細**: 具体的な内容（例: "温度を26°Cに設定"、"風量を強に変更"）
- **トリガー**: [manual | alert | scheduled | other]
- **気温（Tapo）**: XX.X°C
- **湿度（Tapo）**: XX%
- **備考**: 任意のメモ
```

## 2026年8月

### 2026-08-02 22:41 (JST)
- **アクション**: sensor_relocation
- **詳細**: Tapo温度・湿度センサーを窓際から水槽近くに移動
- **トリガー**: manual
- **移動前位置**: 窓際（左の赤丸位置）
- **移動後位置**: 水槽の近く（水槽から30～50cm程度の距離、直射日光を避けた位置）
- **目的**: 水槽周辺の実温度を正確に測定するため
- **備考**: 
  - 移動前は窓際の直射日光や外気の影響で実温度より高めに記録されていた可能性
  - 移動後1～2日間のデータで、温度パターンの変化と適切なアラート閾値を再評価予定
  - Phase 1aの監視システム構築前の重要な準備ステップ

## 記録のヒント

- **エアコン操作**: ON/OFF、温度変更、風量変更をそれぞれ記録
- **ファン操作**: Tapoスマートプラグ経由のON/OFF（スケジュール/手動を区別）
- **気温・湿度**: Tapoアプリから現在値を確認して記録
- **備考欄**: 気づいたこと（水槽の魚の様子、部屋の状態など）を自由に記載

## 今後の展開

Phase 1aのESP32実装完了後は、以下のデータが自動的にBigQueryに記録されます：
